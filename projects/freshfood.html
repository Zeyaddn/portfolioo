FreshFood Storefront

Organic grocery market & express cart

Open live demo ↗ Web Developer · 2023
01 — The problem

A grocery shop needs a fast, lightweight storefront where customers can add items and see the total update instantly, without a heavy framework slowing the page down.

02 — The solution

A storefront built with semantic HTML, CSS3 layout and vanilla JavaScript ES6. The cart recalculates totals live as you shop, with micro-interactions and no external dependencies.

03 — What I built
  • —Live shopping cart with automatically recalculated totals
  • —Semantic HTML5 structure for SEO-friendly markup
  • —Responsive CSS3 Flexbox & Grid layouts
  • —Vanilla JavaScript ES6 with zero framework dependencies
  • —Micro-interactions for a lightweight, fast experience
04 — Challenges & fixes
CHALLENGE

The cart total must update instantly with every add and remove — and there's no framework managing state for us.

FIX

One vanilla state object and a tiny render layer recalculate totals on every change, straight from the DOM events.

CHALLENGE

The storefront has to feel alive with micro-interactions but stay lightweight — no animation libraries allowed.

FIX

CSS-only transitions for hover and focus plus a ~10KB hand-written JavaScript layer, with zero external dependencies.

CHALLENGE

Going framework-free meant keeping the code readable and the layout solid across screens without turning it into spaghetti.

FIX

Semantic HTML5 with Flexbox and Grid, and functions split by concern so the cart, filters and layout stay maintainable.

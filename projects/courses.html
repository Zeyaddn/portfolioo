Saudi LMS Platform

Learning management system with RTL support

Open live demo ↗ Frontend & System Architect · 2024
01 — The problem

Learning content has to follow the SCORM 2004 standard, and Arabic-speaking students and admins need an interface that reads right-to-left.

02 — The solution

A Next.js learning system with SCORM 2004 support, a separate dashboard for students and one for admins, and a fully responsive RTL interface. Components are built and documented in Storybook so they can be reused.

03 — What I built
  • —SCORM 2004 compliant course delivery
  • —Separate student and admin dashboards
  • —Responsive RTL interface for Arabic users
  • —Component library documented in Storybook
04 — Challenges & fixes
CHALLENGE

A course that doesn't talk to the LMS is just a website — SCORM 2004 has strict expectations around progress, completion and reporting.

FIX

Built a SCORM adapter over the Next.js runtime that mirrors the LMS data model, commits state at the right moments, and survives refreshes mid-course.

CHALLENGE

The interface is for Arabic users, and a left-to-right layout quietly breaks on nearly every RTL screen.

FIX

Built the design system RTL-first with logical properties, so every layout, slider and menu mirrors correctly in Arabic.

CHALLENGE

Two very different dashboards (student and admin) sharing one codebase meant duplicated components and silent drift.

FIX

Extracted the UI into a Storybook-documented component library, so both dashboards consume the same tested building blocks.

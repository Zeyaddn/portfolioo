TravelSphere

Destination discovery & tour booking

Open live demo ↗ React Frontend Developer · 2023
01 — The problem

Travellers want to browse destinations, filter them quickly and see what a tour costs before they book.

02 — The solution

A React app that loads destination data from an API, filters it instantly, shows tour schedules and calculates costs, with a responsive gallery built from a Figma design system.

03 — What I built
  • —API-driven destination data
  • —Instant filtering
  • —Tour schedules
  • —Dynamic cost calculation
  • —Reusable components
04 — Challenges & fixes
CHALLENGE

Destination filtering had to feel instant as the catalog grows, without blocking input or showing stale results.

FIX

Client-side indexed filtering with memoized results — the list re-renders in a single pass on every selection.

CHALLENGE

Tour costs depend on the chosen configuration, and a wrong price destroys trust before booking.

FIX

All cost math lives in one pure function fed by the latest state, so the price shown is always the price at checkout.

CHALLENGE

Destinations come from an external API — loading states, failures and slow networks all needed graceful handling.

FIX

Wrapped the Fetch calls with loading and error states, and normalized the payload so the UI never fights over field names.

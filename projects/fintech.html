FinTech Money System

Banking dashboard (demo)

Open live demo ↗ Full Stack Engineer · 2024
01 — The problem

Users need to see their balance, send money and check their history in one clear screen, without the screen getting cluttered.

02 — The solution

A Next.js dashboard built to look and behave like a modern banking app: balance tracking, deposits and transactions, filterable history, invoice generation, and profile settings. This is a demo UI and is not connected to a real bank.

03 — What I built
  • —Account balance tracking
  • —Deposit and transaction management
  • —Transaction history with filters
  • —Invoice generation
  • —Profile and settings
04 — Challenges & fixes
CHALLENGE

A banking UI lives and dies on trustworthy numbers — balance, deposits and transfers on one screen with zero room for calculation drift.

FIX

Centralized every money calculation in TypeScript-typed modules and drove all views from one state source, so the balance can never disagree with history.

CHALLENGE

Balance, send, history and invoices had to fit on one clear screen — cramming features in just made it feel like a spreadsheet.

FIX

Typed filters and memoized lists keep the history responsive, while the layout groups the essentials and hides rarely-used actions.

CHALLENGE

Filtering a long transaction history had to stay instant without re-drawing the whole dashboard on every keystroke.

FIX

Deferred rendering and memoized filter results, so the list updates immediately while the rest of the screen stays idle and stable.

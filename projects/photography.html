Photography Portfolio & Booking

Portfolio with calendar scheduling

Open live demo ↗ Full Stack Developer
01 — The problem

A photographer needs a portfolio that presents the work well and a way for clients to book a session without back-and-forth messages.

02 — The solution

A Next.js portfolio with story-style pages, a calendar booking system for client reservations, and image protection (right-click disabled, overlay watermark) on the gallery.

03 — What I built
  • —Story-style pages across the portfolio
  • —Calendar scheduling for client reservations
  • —Image protection with overlay watermark
  • —Performance focused: scores above 85
04 — Challenges & fixes
CHALLENGE

A photographer's portfolio lives or dies on image quality — but heavy galleries destroy load time and mobile data.

FIX

Optimized every asset and lazy-loaded below-the-fold shots, keeping performance-scores above 85.

CHALLENGE

Clients should book a session without back-and-forth messages, and double bookings would wreck the calendar.

FIX

Built a calendar-based booking flow that takes the chosen slot, manages conflict-free scheduling, and returns a clear confirmation.

CHALLENGE

Watermarked work gets screenshotted and reused — the gallery needed to make casual copying noticeably harder.

FIX

Disabled the context menu on gallery images and added an overlay watermark across the pages.
